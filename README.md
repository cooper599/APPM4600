This read me file is a short explanation of how this repository for APPM 4600 works. The general format is as follows: Folder name - APPM4600, within has 3 files the README.md this file, the Labs folder, and Homework folder. Within Labs there are Lab 1, Lab 2... for all labs, and those folders contain the files and images created in each respective lab. The Homework folder will follow a simular format with Homework 1, Homework 2... for all homeworks throughout the semester, and will hold the code needed for homeworks throughout, or images generated.
